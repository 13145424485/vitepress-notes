# `/work/` 面试卡片补全设计

## 目标

让 `/work/` 首页完整展示已经提交的两篇公司面试记录：小红书 Java 后端一面、喜马拉雅 Java 后端一面。

## 根因

两篇 Markdown 文档已经存在并同步到 `origin/master`，但 `work/index.md` 的 `features` 列表没有引用它们，因此页面内容不会随文档提交自动增加。

## 方案

保持 VitePress 默认首页和现有三列卡片布局。在 `work/index.md` 的现有卡片末尾追加两项：

- 小红书 Java 后端一面，链接 `/work/小红书Java后端一面`
- 喜马拉雅 Java 后端一面，链接 `/work/喜马拉雅Java后端一面`

同时在 hero 的 `tagline` 中加入“公司面试记录”，让页面描述覆盖新增内容。除此之外不修改主题组件、全局样式或导航结构。

## 验证

先以自动检查确认两个入口当前缺失，再修改索引，并验证：

1. `work/index.md` 同时包含两张卡片及正确链接。
2. `pnpm docs:build` 成功。
3. 构建产物包含两个页面入口，且原有卡片不受影响。
